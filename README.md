# Password Generator - Mini Project 1

This is a simple Password Generator Web Application made using HTML, CSS, and JavaScript.

## Features

- Generate random passwords
- Select password length from 4 to 32 characters
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include special characters
- Copy generated password
- Basic password strength indicator
- Responsive design for mobile and desktop

## Technologies Used

- HTML
- CSS
- JavaScript

## File Structure

```text
password-generator-mini-project/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Steps To Run The Project

1. Download or clone this project folder.
2. Open the `index.html` file in a web browser.
3. Select the password length.
4. Choose character options.
5. Click the `Generate Password` button.
6. Click `Copy` to copy the password.

## How To Upload On GitHub

1. Create a new public repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Commit the files.
4. Go to repository `Settings`.
5. Open `Pages`.
6. Select the branch as `main`.
7. Save and wait for GitHub Pages to create your live link.
